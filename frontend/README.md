# WebVerity Frontend

## Status
Frontend development is slated for Day 2+ of the WebVerity roadmap.

Day 1 focus is dedicated to the core security scanning engine, API contracts, SSRF defenses, TLS cryptographic analysis, DNS resolution, and rule-based risk evaluation.

When frontend development begins, this directory will host the client application (Next.js/React with Tailwind CSS) consuming the `/api/v1/scans` endpoints.
